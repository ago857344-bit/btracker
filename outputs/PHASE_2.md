# Phase 2 — Global application shell

The temporary Phase 1 page has been replaced by the responsive BTracker shell.

- Fixed, collapsible desktop sidebar with the requested Trackly-inspired information hierarchy.
- Mobile drawer navigation with an accessible scrim and Escape-key close action.
- Responsive top bar with breadcrumb, native save-status indicator, theme toggle, and quick task entry point.
- All requested sections now have stable, meaningful routes and intentionally scoped placeholders ready for their data-specific phases.
- The layout uses only original tokens and icons; no Trackly assets, code, or functional data were copied.
